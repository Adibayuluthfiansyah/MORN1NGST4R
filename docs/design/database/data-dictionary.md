# Data dictionary

Status: design proposal for owner review. Nothing here is implemented. Design decisions carry `DB-nn` identifiers (see `README.md`). Open questions carry `DQ-nn`. **M3 update (2026-11-18):** the M3 slices are implemented in `services/core/migrations` (00001 to 00007, 00013 to 00015). The result, the rulings and the differences from this design are in `.kiro/specs/mvp/plan.md`, section "Milestone M3".

This dictionary lists 59 tables and 631 columns. Types are PostgreSQL types. Timestamps are `timestamptz` and use the database clock. Identifiers are UUIDv7 generated by the application (DB-04). Enumerations are constrained `text` with named CHECK constraints (DB-02). Nothing is deleted with `ON DELETE CASCADE` (DB-05). Every foreign key is `ON DELETE RESTRICT ON UPDATE RESTRICT`.

**Column constraint references** such as `c3` point to the numbered constraint list of the table in `constraints-and-indexes.md`.

**Sensitivity classes.** I = Internal; T = Target data; A = Authentication-derived (hash); U = Untrusted text; E = Evidence metadata; L = Audit; P = Personal (low); X = Secret reference (never the secret). No column holds a plaintext secret. Password, recovery code, bootstrap secret, session token and CSRF token appear only as hashes (class A). Provider keys and tool credentials appear only as Secret Service references (class X, D-52).

**Retention classes.** `RC-A` Authorization and audit history. Kept indefinitely in the MVP. Only the retention procedure may remove rows, and not before a human archive. `RC-B` Security-operational state. Purged after expiry plus 30 days (proposed, DQ-07). `RC-C` Assessment data. Kept until the human archives or purges the assessment. `RC-D` Evidence. Content kept until an explicit audited purge (D-77). Metadata is kept after purge. `RC-E` Configuration. Kept while configured. Deleted references stay as audit rows.

**Table kinds.** immutable (no update after insert), append-only (insert only), immutable-except-X (one named column changes), mutable-projection (derived state rebuilt from append-only history), mutable (ordinary state with version counter).
